# SHOPLINOUS AFRICA — vitrine publique

Ce dossier contient la première version de la vitrine publique indépendante de Freewebstore.

## État actuel

- Page d'accueil responsive, mobile-first.
- Navigation mobile accessible.
- Présentation des univers de produits.
- Catalogue volontairement en état « en préparation » : aucun stock, prix, avis, délai ou moyen de paiement fictif.
- Bases SEO : titre, description, Open Graph, viewport et structure sémantique.
- Aucune transaction, collecte de données client, commande fournisseur ou campagne publicitaire n'est activée.

## Prochaines étapes

1. Ajouter les pages catalogue, fiche produit, panier et suivi de commande.
2. Créer une API serveur et connecter le catalogue qualifié existant.
3. Brancher Supabase avec politiques d'accès et migrations testées.
4. Connecter GeniusPay en Sandbox et vérifier les webhooks signés.
5. Ajouter les pays et moyens de livraison uniquement après validation réelle.
6. Tester puis préparer un déploiement distinct de l'ancien tableau de gestion.

## Prévisualisation locale

Ouvrir `index.html` dans un navigateur. Cette première vitrine est statique ; elle n'est pas encore connectée à une base de données ni publiée en production.
